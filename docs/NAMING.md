# Naming

## Selected name

# AETHRA

**Adaptive Edge Task & Hybrid Reasoning Assistant**

Why it fits:
- sounds like a named assistant rather than a generic SaaS product
- EDITH-style acronym
- "Edge" reflects local/on-device execution
- "Task" reflects agentic workflows
- "Hybrid Reasoning" reflects Needle + larger cloud/local LLM collaboration
- not tied to one model/provider/tool ecosystem.

Recommended:
- Display name: `Aethra`
- Technical/project name: `AETHRA`
- Repository slug: `aethra`
- Package prefix: choose a domain you control before publishing.
